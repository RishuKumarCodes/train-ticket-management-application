# User & Administrator Manual
## RailFlow — Train Ticket Management Application
**Document Status:** Working User Manual (To be updated with screenshots as UI is implemented)

---

## 1. Passenger Workflow

### 1.1 Searching Trains
1. Launch RailFlow and open the **Train Search** screen.
2. Select the **Origin Station** and **Destination Station** from the station search dropdowns.
3. Select the intended date of journey and click **Search Trains**.
4. Review available train services, scheduled departure/arrival times, travel durations, and fares across coach classes.

### 1.2 Interactive Seat Selection
1. Click **View Seats** on the chosen train.
2. Review the visual coach map showing seat arrangements (Lower, Middle, Upper, Side Berths, Window).
3. Select the desired available seats. Selected seats will highlight immediately.

### 1.3 Passenger Details & Reservation
1. Enter passenger names, ages, and berth preferences.
2. Review booking summary and total fare breakdown.
3. Confirm booking to generate the **10-digit PNR** and view/print the booking confirmation ticket.

---

## 2. Administrator Workflow

1. Log in with administrative credentials.
2. Open the **Admin Dashboard** to:
   - Add new trains and configure coach compositions.
   - Schedule train departures, manage intermediate halts, and update train operational status (`ON_TIME`, `DELAYED`, `CANCELLED`).
   - Monitor real-time seat occupancy and view booking reports.
